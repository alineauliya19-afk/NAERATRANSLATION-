NAERA TRANSLATION — PETUNJUK UPLOAD GITHUB PAGES

UPLOAD KE ROOT REPOSITORY (BUKAN ZIP):
1. index.html
2. index-en.html
3. style.css
4. script.js

LANGKAH:
1. Ekstrak ZIP ini di HP atau komputer.
2. Buka repository GitHub NAERATRANSLATION-.
3. Hapus atau ganti versi lama dari empat file di atas di root repository.
4. Upload empat file baru (jangan upload ZIP saja), lalu Commit changes.
5. GitHub Settings > Pages > Deploy from a branch > main > /(root).
6. Tunggu deployment dan refresh paksa halaman (atau buka di tab samaran).

FILE LAMA YANG PERLU DITINJAU:
- ZIP revisi lama: boleh dihapus dari repository untuk menghindari kebingungan.
- our-team.html: tidak digunakan oleh navigasi versi ini; hapus hanya jika tidak dipakai.
- supabase.sql: tidak dibutuhkan website statis ini; jangan hapus bila masih dipakai proyek lain.
- README lama: perbarui jika masih menyebut tema hitam-emas atau FormSubmit.
