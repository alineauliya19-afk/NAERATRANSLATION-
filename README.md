# NAERA TRANSLATION website

## Isi website
- `index.html`: halaman Bahasa Indonesia
- `index-en.html`: halaman Bahasa Inggris
- `style.css`: tampilan responsif bernuansa hitam dan emas
- `script.js`: menu mobile dan formulir email melalui FormSubmit

## Upload ke GitHub Pages
Unggah semua file ke folder utama repository, lalu commit changes. Bahasa Indonesia menggunakan `index.html`; versi Inggris tersedia melalui tautan English di menu.

- Harga: Reguler Rp30.000 per halaman (estimasi 7–8 hari); Fasttrack Rp65.000 per halaman (estimasi 4–5 hari).
