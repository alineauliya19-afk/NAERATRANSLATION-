# NAERA TRANSLATION — Website Company Profile

Website profil responsif NAERA TRANSLATION dengan tema hitam dan emas.

## Isi paket
- `index.html` — website publik dan formulir kontak
- `style.css` — desain responsif
- `script.js` — menu dan pengiriman formulir ke email melalui FormSubmit
- `README.md` — panduan upload dan aktivasi formulir

## Upload/update website lewat GitHub
1. Ekstrak ZIP ini.
2. Buka repository GitHub yang sudah dipakai untuk NAERA TRANSLATION.
3. Tekan **Add file > Upload files**.
4. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` dari folder ini ke folder utama repository. Jika diminta, pilih untuk mengganti file yang sudah ada.
5. Tekan **Commit changes** dan tunggu GitHub Pages memperbarui website.

## Mengaktifkan formulir email
Formulir diarahkan ke FormSubmit agar tidak perlu Supabase atau database.
1. Buka website NAERA TRANSLATION yang sudah diperbarui.
2. Isi formulir menggunakan data uji lalu kirim.
3. Buka Gmail `alineauliya19@gmail.com`, cari email konfirmasi dari FormSubmit, lalu tekan tautan konfirmasi.
4. Setelah email dikonfirmasi, kirim formulir uji sekali lagi dan periksa Inbox/Spam.

Layanan FormSubmit adalah layanan pihak ketiga. Pengiriman pertama memerlukan verifikasi email. Jika tidak menerima email, periksa folder Spam dan halaman bantuan FormSubmit.

## Catatan penting
- Website tetap di-host di GitHub Pages; tidak perlu membuat website baru.
- Paket ini tidak memakai Supabase.
- Dashboard admin lama tidak disertakan karena dashboard tersebut bergantung pada Supabase. Pesan formulir akan masuk ke email, bukan tampil di dashboard website.
- Jangan memasukkan kata sandi atau informasi sangat sensitif ke formulir.
- Galeri pada website adalah ilustrasi konsep, bukan portofolio klien nyata.
